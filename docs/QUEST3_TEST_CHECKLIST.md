# Quest 3 實測清單（v0.1）

請逐項標 ✅／❌／⚠️，並附上簡短描述。有影片或截圖更好，可以用 Quest 的錄影功能。
另外請記下：Quest 系統版本、Quest Browser 版本、使用手部追蹤還是控制器、站姿或坐姿、遊玩空間大小。

## A. 啟動
- [ ] A1 從 `https://<Mac IP>:8443` 或 `http://localhost:5173`（adb）能開啟主畫面，畫面上有房間、夕陽和 MOBIUS 標誌
- [ ] A2 狀態列顯示「Meta Quest 已就緒」
- [ ] A3 語言下拉選單在 English 和繁體中文之間切換正常，重新整理後仍然保留
- [ ] A4 主音量滑桿有作用
- [ ] A5 按「進入 VR 遊戲」能進入沉浸模式，眼前出現模式選單
- [ ] A6 從 Quest 系統選單離開或回到 VR 時，遊戲沒有卡住；回到瀏覽器時顯示「VR 已結束」

## B. 選單與輸入
- [ ] B1 用手部捏合射線或指尖直接點，都能點選按鈕
- [ ] B2 控制器射線加扳機能點選
- [ ] B3 手心朝向自己時，左手掌心會出現圓形按鈕；右手食指靠近時發亮，按下去開啟選單
- [ ] B4 按住掌心按鈕不會重複觸發，手指要移開才能再次觸發
- [ ] B5 選單開著時，光網和炸彈都不會發射
- [ ] B6 手部追蹤遺失再恢復時（例如把手藏到背後再拿出來），不會誤射
