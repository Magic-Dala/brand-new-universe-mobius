# 世界座標（v0.20 模組化達拉城）

座標來源：`src/data/cityConfig.js`（網格與所有串流參數）、`src/data/blocks.js`（模組內容）、`src/data/route.js`（路線）、`src/data/cityWorld.js`（世界空間的街區、碰撞、錨點）、`src/data/layout.js`（房間、故事路線、檢查點、光圈、工廠 C）。單位公尺；+Y 朝上，重力永遠是 −Y。環形城市與倒置上層城市已在 v0.20 移除。

## 網格
- 每格 72 m，以**十字路口為中心**：格 (i, j) 的中心 = ((i − oi)·72, −24 + (j − oj)·72)。`oi, oj` 是原點格（原點重設時改變，故事模式永遠是 0, 0）。
- 街道寬 24 m（車道 14 m＋兩側人行道 5 m），四個角各一塊 24 m 的建築角落，所以相鄰路口之間的城市街區是 48 m。
- 方向：heading 0 = 北（−Z）、1 = 東（+X）、2 = 南、3 = 西；模組局部座標的前方是 −Z，`yaw = −heading·π/2`。
- 局部轉世界：`x = cx + lx·cos + lz·sin`、`z = cz − lx·sin + lz·cos`（cos／sin 已四捨五入成 0／±1）。

- 追逐路線全長 527.7 m；右轉在 s ≈ 438 m；屋頂光圈 (94, 21.6, −460)，r 1.5。
- 檢查點：`cp-start`（房間）與 `cp-t1` … `cp-t6`（每個模組一個，掛在立面上）；只有在該街區已建好且未回收時才會使用。

## 無盡路線
- 從模組 9 開始，主方向向東，以階梯方式左右偏移（每次最多 3 個模組再回正），永遠不會回頭或自交。
- 至少 2 個直行後才會出現轉彎或路口；路口在綠狂魔帶路期間（6 個模組）自動決定，之後玩家擺盪進入哪個出口就走哪個，其他方向變成路邊街區。
- 原點重設：離原點超過 1500 m（且沒有掛在網上）時整個世界平移整數格，所有系統收到 `rebased(dx, dz)`。

## 工廠 C（外觀）
C 的方盒座標（C 旋轉了 −90°）：方盒 −Z 面朝世界東方（鐵捲門那一面，面向出口模組），y = 屋頂上方高度。紫褐色磚牆、深灰鋼構柱、暖黃高窗、鐵捲門與卸貨平台（v0.20 另有預做的破門版本：撕裂的門片殘段＋掉在卸貨平台與街上的門板）、外露管線、通風口、金屬屋頂、少量南瓜燈、橘／紫燈光；沒有任何 Logo。碰撞仍是一個方盒（屋頂 = 方盒頂面）。

| 物件 | C 局部座標 |
|---|---|
| 屋頂藍色光圈 | (−4, +9)，r 1.5 |
| 可炸開的屋頂區塊 | 中心 (−4, +9)，半寬 3.4 × 3.4 |
| 煙囪（錨點 `C-STACK`） | (7.5, 14)，高 20 m |
| 高側窗屋頂（monitor） | x 1.5–8.5、z −16.5 – −2 |
| 屋頂設備禁區（不能傳送） | `FACTORY_EXT.equipment` |
| 投彈時綠狂魔的位置 | 玩家面前 7.5 m、屋頂上 7.5 m（夾在屋頂範圍內） |

屋頂狀態：`intact`（正常）→ 炸開後 `broken`（破洞＋只有那一塊沒有碰撞＋下方 7 m 的暗色短井）→ 打完 Boss 之後 `netted`（光網蓋住破洞）；鐵捲門 `closed` → `broken`（綠狂魔撞出去）。v0.20 起打完 Boss 不再回屋頂，而是從鐵捲門出去進入無盡擺盪。
